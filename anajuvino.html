Sobre esta página

Esta página usa apenas HTML e CSS, sem nenhuma biblioteca externa. Todo o estilo está dentro da tag <style>, no cabeçalho do arquivo.

Abra o arquivo em um editor de texto e altere os valores dentro de :root para ver a paleta de cores mudar na página inteira.

Tags usadas aqui

  • <header> — o topo da página
  • <nav> — o menu de links
  • <main> — o conteúdo principal
  • <section> — cada bloco de assunto
  • <h1> a <h6> — títulos, do mais importante ao menos
  • <p> — parágrafos de texto
  • <ul> e <li> — listas
  • <a> — links
  • <footer> — o rodapé
